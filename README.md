# SLC-skill｜學習共同體課例探究與簡報生成

此 Skill 將公開課影片轉化為可追溯的學習共同體課例分析，並輸出最高畫質影片、雙語字幕、16:9 PPTX、一頁式 HTML 與連續角色插圖。

## 核心產出

- 最高畫質影片與音訊
- 原語 SRT（含中文、日文發音）與原語／繁中雙語 SRT（Groq 優先、本機 Whisper 備援；經教材與課室用語二次校正）
- 對齊 NotebookLM 架構的「描述－詮釋－反思」分析稿
- 逐頁影片影格、16:9 日本溫潤水彩繪本插圖、1080×1920 直式影片插圖
- 可編輯 16:9 PPTX 與一頁式向下捲動 HTML

## 完整工作流程

1. 選擇 `learning`、`pastel`、`blue` 或 `modern` 視覺主題。
2. 下載 YouTube 可取得的最高畫質視訊，合併最佳相容音訊。
3. 詢問使用者選擇語音辨識引擎：**優先 Groq Whisper-large-v3-turbo**（使用者自行至 https://console.groq.com/keys 申請 API Key，Agent 只提供網址不代為註冊），**備援本機 Whisper medium**。兩者都保留影片中的中文與日文發音。
4. **字幕校正（必做，直接調用 `classroom-video-analysis/scripts/subtitle_qc.py`）**：向使用者要本堂課教材（課本 PDF、學習單、教案、PPT、板書照片或名詞清單），依序執行 `boost`（音訊增益）→ `transcribe`（帶兩層詞彙表：教材層 + 含學習共同體用語的課堂語言層）→ `clean`（清幻覺與簡體）→ `collate`（對照教材校正）→ `verify`（重聽立論句）。時間碼與段數不動、不把口語改成書面語。校正後才輸出雙語字幕與逐字稿。
5. 詢問是否使用 NotebookLM 筆記，並以指定的學習共同體哲學架構完成帶時間碼的分析。
6. 逐頁對照投影片標題、分析焦點、SRT、逐字稿與影片時間碼，擷取原始影格。
7. 先只生成第一頁 PPTX 與插圖預覽；使用者確認後才批量製作其餘頁面。
8. 每頁使用對應影格作為 `referenced_image_paths` 基底，重繪日本溫潤水彩繪本插圖。不可僅用文字提示生圖。
9. 第一頁插圖成為角色連續性母圖：後續頁面固定教師、學生外觀、座位、桌椅與教室配置，只調整動作、表情與眼神。
10. 移除觀課師長；授課教師只在直接參與學生學習時保留。人物與教室物件完整入鏡，黑板不得有可讀文字。
11. 全套簡報維持 **15–20 頁**；頁數不足時，以分析架構、關鍵學習事實、描述／詮釋／反思與團隊反思拆分為語意完整頁面，不以重複內容或硬刪文字湊頁數。
12. 使用固定簡報母版：上方白色標題框、左側白色文字卡、右側 16:9 插圖。內文字級以 26–28 pt 為目標，先重寫完整句意再調整版面。
13. 以最終 PPTX 為文字來源生成一頁式、向下捲動 HTML，使用相同插圖與固定頁碼導覽，且 HTML 頁數必須與 PPTX 一致。
14. 完成影片解析度、字幕時間碼、圖片比例、文字不溢出、PPTX 頁數 15–20 頁、HTML 無問號／亂碼／失效連結的檢核後，再分類交付檔案。

## 必要規則

- 影片必須使用可取得的最高畫質，不得以低畫質便利格式替代。
- 語音辨識與字幕校正一律調用 `classroom-video-analysis` 的 `subtitle_qc.py`（需先安裝該技能到 `~/.claude/skills/`），校正完成才可進入雙語字幕與分析；Groq API Key 由使用者自行申請，Agent 不代為註冊。
- 橫式插圖必須為 16:9，直式插圖最終尺寸必須為 1080×1920。
- PPTX 文字不得被插圖遮蔽、不得超出文字框或頁面；不可將插圖拉伸成正方形。
- 分析段落不得用硬切字數的方式縮短，必須保留可獨立理解的完整語意。
- HTML 必須是單一頁面、向下捲動，而非投影片左右切換介面。

## 交付檔案結構

```text
output/
├── 字幕檔/       # 原語 SRT、雙語 SRT、逐字稿與分段辨識
├── 簡報/         # PPTX、單頁 HTML、分析稿
├── 影片/         # 最高畫質影片與音訊
├── 圖檔/         # 社群圖與橫式素材
├── screenshots/  # 逐頁原始影片影格
├── drawings/     # 16:9 重繪插圖
└── drawings_vertical/ # 1080×1920 直式插圖
```

## 安裝

將整個資料夾複製到 Codex 全域技能目錄：

```text
C:\Users\<user>\.codex\skills\slc-skill
```

重新開啟工作階段後即可用 `slc-skill` 啟動流程。
